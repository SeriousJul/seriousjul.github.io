Toolchain shipped major release v5.0.0 on 2025-03-12, introducing a breaking change to the config schema and reducing cold-start time by roughly 40%. It was quickly followed by v5.0.1 on 2025-03-14, which fixed a high-severity security issue (CVE-2025-99887) in the plugin loader. A preview of the new plugin marketplace also went live during the window.

## Releases
- v5.0.0 was released on 2025-03-12. It introduces a breaking change to the config schema (old `plugins` list becomes a `plugins:` map) and cuts cold-start time by about 40%. Migration instructions are in the release notes. See [GitHub release](https://github.com/acme/toolchain/releases/tag/v5.0.0).
- v5.0.1 was released on 2025-03-14 to patch the plugin-loader vulnerability; upgrading is strongly recommended. See [GitHub release](https://github.com/acme/toolchain/releases/tag/v5.0.1).
- v4.3.2 was released on 2025-03-10 as a patch for the last 4.x line, fixing a rare infinite retry loop in the build cache. See [GitHub release](https://github.com/acme/toolchain/releases/tag/v4.3.2).

## Features
- A preview of the plugin marketplace was published on 2025-03-13. It lets teams browse, pin, and share internal plugins, and is disabled by default until a `marketplace:` config block is added. See [docs preview](https://toolchain.dev/docs/plugins-preview).

## Fixes and other
- The security fix in v5.0.1 addresses CVE-2025-99887, a path traversal in the plugin loader rated high severity (7.2 CVSS). Details are in the [security advisory](https://github.com/acme/toolchain/security/advisories/GHSA-2025-99887).
- A new migration guide for upgrading from v4 to v5 was published on 2025-03-11, covering config changes and CLI flags that were removed. See [migration guide](https://toolchain.dev/docs/migration-5).

## Community
- The monthly newsletter (#42) was published on 2025-03-14, covering the plugin marketplace launch, a call for community plugin authors, and a 2025 roadmap Q&A. See [newsletter](https://toolchain.dev/newsletter/2025-03).
