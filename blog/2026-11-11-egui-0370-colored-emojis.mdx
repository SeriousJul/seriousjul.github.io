Egui released version 0.37.0 ("Colored emojis!") on 2026-10-15. The release adds rendering of any system glyph, including colored emojis and non-Latin scripts, through new GlyphRasterizer and FontProvider APIs, and ships a CompletionPopup widget for TextEdit autocomplete.

## Releases
- 2026-10-15: egui 0.37.0 ("Colored emojis!") released, the latest stable version of the crate ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).

## Features
- Any system glyph can now be rendered, including colored emojis and non-Latin scripts, via the new GlyphRasterizer and FontProvider APIs (0.37.0) ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
- New CompletionPopup widget provides autocomplete support for TextEdit (0.37.0) ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
- Experimental widget theme plugin system introduced (0.37.0) ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
- egui_kittest can now record mp4 videos of integration tests (0.37.0) ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
