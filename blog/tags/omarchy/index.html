Omarchy 4.0.5 ships Qt 6.12 and BORE-scheduler kernel

October 18, 2026 · 2 min read
Julien Antony
Systems tinkerer

Omarchy 4.0.5 was released on 18 October 2026 as a stable point release bringing fixes and refinements ahead of the next feature release. The update moves the distro onto the Qt 6.12 toolkit, bumps stable-ring packages, and ships an updated Linux 7.2 stable kernel with the BORE scheduler. Phoronix also covered the release, highlighting millisecond-level optimization of web browser launch by avoiding XDG overhead.

Releases​

  • v4.0.5 (stable) released on 18 Oct 2026, with a set of fixes and refinements, a move to Qt 6.12, stable-ring package bumps, and an updated kernel with the BORE scheduler; existing machines can upgrade via Update > Omarchy and new installs use the 4.0.5 ISO (GitHub release)

Features​

  • Faster default web browser launch via millisecond-level optimization that avoids the xdg-settings get default-web-browser overhead, as reported on the 4.0.5 release (18 Oct 2026) (Phoronix)

Fixes and other​

  • Improved reliability of Wi-Fi QR code generation among other fixes in v4.0.5 (18 Oct 2026) (GitHub release)

Community​

  • Phoronix (Michael Larabel) covered the 4.0.5 release on 18 Oct 2026, noting it pulls in the Linux 7.2 stable kernel with BORE scheduler and Qt 6.12 updates alongside smaller improvements (Phoronix)
