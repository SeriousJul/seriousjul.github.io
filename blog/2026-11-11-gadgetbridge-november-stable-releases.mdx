Gadgetbridge released two stable versions within the past month. 2026.11.0 (released 2026-11-03) adds initial support for a batch of new devices, while follow-up 2026.11.1 (released 2026-11-07) focuses on dashboard and chart improvements plus regression fixes. Both were published by joserebelo on the project's Codeberg release page.

## Releases

- 2026.11.0 stable released on 2026-11-03, adding initial support for Anker Soundcore Motion+ (R50i NC, V20i), Bettdow FB051 (MoYoung / Da Fit), Beurer BM59, BRAZ/7HARRY (FitPro), Casio GG-B100, and more, as listed in the release changelog. ([source](https://codeberg.org/Freeyourgadget/Gadgetbridge/releases/tag/2026.11.0))
- 2026.11.1 stable released on 2026-11-07 as a maintenance release fixing and improving dashboard, charts, and vendor integrations. ([source](https://codeberg.org/Freeyourgadget/Gadgetbridge/releases/tag/2026.11.1))

## Fixes and other

- 2026.11.1 fixes a crash on weather processing on Android below 13. ([source](https://codeberg.org/Freeyourgadget/Gadgetbridge/releases/tag/2026.11.1))
- 2026.11.1 fixes a regression in Garmin web request URL encoding and improves Zepp OS BTBR packet handling. ([source](https://codeberg.org/Freeyourgadget/Gadgetbridge/releases/tag/2026.11.1))
- 2026.11.1 improves dashboard and charts: centered axis labels, fixed widget management and tile reshuffling on long press, better large font support, awake sleep shown in the day widget, and theme colors applied to sleep chart widgets; it also fixes the Endurain SSO login callback and Health Connect skin temperature deltas. ([source](https://codeberg.org/Freeyourgadget/Gadgetbridge/releases/tag/2026.11.1))
