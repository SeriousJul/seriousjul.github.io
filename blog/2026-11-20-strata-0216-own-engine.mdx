Strata 0.2.16 landed on 18 November 2026, moving every engine (NVIDIA, AMD, Intel Arc, Apple Silicon, DGX Spark) to Strata's own engine code with no ggml or llama.cpp matrix kernels. The release also reorganizes the repository into engine/, app/, terminal/, docs/ and tools/, and fixes a silent correctness bug on Mac M1-M4 from 0.2.15 plus several Windows and Linux crashes. LinuxCompatible covered the release the next day.

## Releases
- Strata v0.2.16 was released on 18 November 2026 (app and Terminal at 0.2.16, engines and Control at 0.1.62, update feed sequence 128). The repo was reorganized into engine/, app/, terminal/, docs/ and tools/, and existing models, chats and settings carry over on update: https://github.com/Niko1221/Strata/releases/tag/v0.2.16

## Features
- All engines now run on Strata's own engine code, dropping ggml and llama.cpp matrix kernels across NVIDIA, AMD, Intel Arc, Apple Silicon and DGX Spark. The developer claims identical model output to the old engine across its test hardware: https://github.com/Niko1221/Strata/releases/tag/v0.2.16

## Fixes and other
- 0.2.16 fixes the wrong-results bug on Mac M1-M4 with UD-Q4_K_XL introduced in 0.2.15, plus several Windows and Linux crash issues: https://github.com/Niko1221/Strata/releases/tag/v0.2.16

## Community
- LinuxCompatible reported on the release on 19 November 2026, headlining that Strata now runs its own engine, drops llama.cpp, and claims identical output across nine tested GPUs: https://www.linuxcompatible.org/story/strata-0216-runs-its-own-engine-drops-llamacpp-claims-identical-output
