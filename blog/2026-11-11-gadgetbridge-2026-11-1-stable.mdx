Gadgetbridge shipped stable release 2026.11.1 on 2026-11-07, a point release focused on dashboard widgets, sleep/HRV chart polish, and several device and platform fixes. The same week, version 2026.11.0 (build 256) appeared as a suggested update on F-Droid, where its release notes highlight 25 new plus 21 experimental devices and a refreshed design.

## Releases
- 2026.11.1 stable was released by joserebelo on 2026-11-07. The changelog covers dashboard widget fixes and improvements (manage widgets setting, tile reshuffling, large font support, theme colors for sleep/HRV charts), Endurain SSO login callback fix, a weather-processing crash fix on Android < 13, a Garmin web request URL-encoding regression fix, Health Connect skin-temperature delta correction, and improved Zepp OS BTBR packet handling. ([source](https://codeberg.org/Freeyourgadget/Gadgetbridge/releases/tag/2026.11.1))

## Community
- On 2026-11-06 the F-Droid repository listed Gadgetbridge 2026.11.0 (build 256) as a suggested update, with release highlights including support for 25 new plus 21 experimental devices, a refreshed design for dashboard, charts, and alarms, device cards, a workouts tab, Garmin import from the official app, and multiple fixes for charts, Health Connect, Huami, Xiaomi, and Zepp OS. ([source](https://f-droid.org/packages/nodomain.freeyourgadget.gadgetbridge/))
