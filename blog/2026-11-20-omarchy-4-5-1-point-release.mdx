Since the Omarchy 4.5 release, maintainer activity has been split between the first point release, 4.5.1, and a busy stretch of feature merges on the next version. Ryan Hughes merged a PR backporting 46 bug fixes toward 4.5.1, while DHH merged several headline features including Omaview, two new default games, and Fantasi as a default app.

## Releases

- Omarchy 4.5.1 point release takes shape: on November 17, maintainer Ryan Hughes merged a pull request backporting 46 bug fixes toward the first point release of Omarchy 4.5 (https://omarchycentral.com/section/releases/).

## Features

- Omaview replaces imv and mpv: DHH merged a pull request on November 15 replacing the separate imv image viewer and mpv player with Omaview, Omarchy's own unified media viewer, for the next version (https://omarchycentral.com/section/releases/).
- Two new default games: DHH merged two pull requests on November 16 adding Cards (Klondike solitaire) and Checkmate (3D chess) as default apps (https://omarchycentral.com/section/releases/).
- Fantasi becomes a default app: DHH merged a pull request into the quattro branch on November 18 making Fantasi, Omarchy's local image maker, a default app (https://omarchycentral.com/section/releases/).
- First-boot setup expands: on November 14, first-boot setup was merged to gain the installer's screens, plus OEM branding and an agreement step, for machines prepared by others (https://omarchycentral.com/section/releases/).
- T3 Code adopts full Omarchy theming: Ryan Hughes merged a pull request on November 18 so T3 Code now follows Omarchy's fonts, chrome, and corner styles, not just its colors (https://omarchycentral.com/section/releases/).

## Fixes and other

- Slack theme sync removed before shipping: DHH merged pull request #18788 on November 15 to remove live Slack theme sync after Slack 4.53 refused to launch with it, pulling the feature before it reached a release (https://omarchycentral.com/section/releases/).
