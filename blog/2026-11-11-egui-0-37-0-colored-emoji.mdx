egui released version 0.37.0 on 2026-10-15, bringing colored emoji with full system glyph rendering, a new CompletionPopup autocomplete widget, and an experimental theme customization system. The release also adds MP4 video recording for integration tests and ships breaking changes, so upgrading projects should expect API and feature-flag adjustments.

## Releases

- On 2026-10-15, egui released version 0.37.0, headlined by colored emoji and full system glyph rendering. The release adds the CompletionPopup autocomplete widget, an experimental theme customization system, and MP4 video recording for integration tests. It also includes breaking changes: default_fonts is no longer a default feature, and new Id APIs were introduced. Source: https://github.com/emilk/egui/releases/tag/0.37.0
