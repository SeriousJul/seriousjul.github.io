Egui 0.37.0, titled "Colored emojis!", was released on 2026-10-15 and is the first release to ship full emoji and glyph support via a new glyph rasterizer and font provider API. The same release adds a CompletionPopup autocomplete widget and an experimental theme plugin system, alongside improved AccessKit accessibility, video recording of integration tests, and breaking changes for API users.

## Releases
- On 2026-10-15, egui released stable version 0.37.0 ("Colored emojis!") featuring full emoji and glyph support through a new glyph rasterizer/font provider API, a CompletionPopup autocomplete widget, an experimental theme plugin system, improved AccessKit accessibility, and video recording of integration tests ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).

## Features
- Full colored emoji and glyph support via a new glyph rasterizer and font provider API, introduced in 0.37.0 on 2026-10-15 ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
- New CompletionPopup autocomplete widget in 0.37.0, released 2026-10-15 ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
- Experimental theme plugin system shipped in 0.37.0 on 2026-10-15 ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
- Improved accessibility through AccessKit and video recording of integration tests, both in 0.37.0 on 2026-10-15 ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).

## Fixes and other
- Breaking changes in 0.37.0 (2026-10-15): the AsId trait was removed and default_fonts was dropped from the default feature set ([source](https://github.com/emilk/egui/releases/tag/0.37.0)).
