n8n published stable release 2.48.6 on 2026-11-19, the newest of three 2.48-series patch releases shipped in this window. The series carried meaningful fixes in 2.48.5, including improvements to the AI Agent Node and core install behavior.

## Releases
- n8n 2.48.6 (2026-11-19): new stable patch release of the 2.48 series; the release notes contain no details beyond the version heading. [Source](https://github.com/n8n-io/n8n/releases/tag/n8n%402.48.6)
- n8n 2.48.4 (2026-11-13): stable patch release in the 2.48 series; no notable release-note details were visible for this build. [Source](https://github.com/n8n-io/n8n/releases/tag/n8n%402.48.4)
- n8n 2.48.5 (2026-11-18): stable release focused on bug fixes. [Source](https://github.com/n8n-io/n8n/releases/tag/n8n%402.48.5)

## Fixes and other
- n8n 2.48.5 (2026-11-18): AI Agent Node now keeps tool-call history separate for each input item, and streaming output no longer inserts extra newlines between text chunks. [Source](https://github.com/n8n-io/n8n/releases/tag/n8n%402.48.5)
- n8n 2.48.5 (2026-11-18): core fixes so fresh installs get a proper instance ID and dollar-property reads in sandboxed expressions are handed to the expression engine. [Source](https://github.com/n8n-io/n8n/releases/tag/n8n%402.48.5)
