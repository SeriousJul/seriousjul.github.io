Omarchy 4.5 (codenamed Quattro RS) shipped on November 5, 2026 as the project's first big feature release since Quattro, after more than 740 pull requests from 180+ contributors in twelve weeks. The headline changes: a traditional desktop mode alongside the tiling default, native installation on Apple Silicon MacBooks (M1/M2/M3/Neo), and interface support for 50 languages. The project also expanded beyond x86_64 for the first time, with reported support for NVIDIA N1X laptops and DGX Spark, while Snapdragon X laptop support is forthcoming.

## Releases

- Omarchy v4.5.0 (Quattro RS) was released to GitHub on November 5, 2026: the first major feature release since Quattro, adding a traditional desktop mode next to the tiling default, a native installer for M1/M2/M3/Neo MacBooks, and 50 languages ([source](https://github.com/omacom/omarchy/releases/tag/v4.5.0)).
- The release was announced on the project's news page on November 4, 2026, with instructions for existing users (Update > Omarchy) and a direct download for new machines ([source](https://omarchy.org/news/2026/11/omarchy-4-5/)).

## Features

- Floating workspaces with a dock: Super + L cycles any workspace between tiling, scrolling, and floating; floating windows get themed titlebars, a dock of pinned and running apps, and Super + M minimizes to the dock ([source](https://omarchy.org/news/2026/11/omarchy-4-5/)).
- Native Apple Silicon support: the Omarchy M team shipped a native Mac installer for M1/M2/M3/Neo MacBooks, building on Asahi Linux work ([source](https://omarchy.org/news/2026/11/omarchy-4-5/)).
- First multi-architecture release: beyond x86_64, Phoronix reports support for Apple Silicon hardware, NVIDIA N1X laptops, and DGX Spark desktops, with Snapdragon X support planned ([source](https://www.phoronix.com/news/Omarchy-4.5-Released)).
- More desktop customizations, including per-monitor workspaces, rebuilt notifications, an Appearance menu, and four new default apps (Hype, Monologue, Signed, Disktree), plus 50 languages ([source](https://omarchy.org/news/2026/11/omarchy-4-5/)).

## Community

- Phoronix covered the release on November 5, 2026, highlighting the distro's expansion beyond x86_64 and its new desktop customization options ([source](https://www.phoronix.com/news/Omarchy-4.5-Released)).
